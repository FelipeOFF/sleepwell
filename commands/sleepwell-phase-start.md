# /sleepwell:sleepwell-phase-start

Opens a new sub-phase inside the current run. Each phase has its own `PLAN.md`,
`EXECUTION.md`, and `VERIFICATION.md`, and is referenced by
`state.phases` in `state.json`.

See `lib/ritual.md §9`.

## Arguments

```
<slug>          kebab-case slug for the phase (required). E.g.: bootstrap, refactor-auth.
--plan <path>   path to a prepared PLAN.md; if missing, generates a template.
```

## Prerequisites

- `.sleepwell/state.json` exists (a run is in progress).
- No phase has `status == "active"` (only one active phase at a time).
  If there is, instruct the user to `/sleepwell:sleepwell-phase-complete` first.

## Behavior

1. Reads `state.json`. Computes next `id`:
   - `id = max(state.phases[].id) + 1`, or `1` if array empty/absent.
2. Directory: `.sleepwell/phases/<NN>-<slug>/` (NN zero-padded to 2 digits).
3. Creates structure:
   - `PLAN.md` — copied from `--plan <path>` if passed, otherwise generates
     template:
     ```markdown
     # Phase <NN> — <slug>

     ## Objective
     <1-2 sentences. What this phase delivers.>

     ## Acceptance criteria
     - [ ] <measurable criterion 1>
     - [ ] <measurable criterion 2>

     ## Scope (in)
     - <item>

     ## Out of scope
     - <item>

     ## Risks / dependencies
     - <item>
     ```
   - `EXECUTION.md` — simple header:
     ```markdown
     # Execution — phase <NN> <slug>

     <append-only log per iteration of the sleepwell-loop skill>
     ```
   - `VERIFICATION.md` — not created now; generated by
     `/sleepwell:sleepwell-phase-complete`.
4. Atomically updates (`tmpfile + mv`) `state.json`:
   - Adds to `state.phases`:
     ```json
     {
       "id": <NN>,
       "slug": "<slug>",
       "status": "active",
       "started_at": "<ISO>",
       "completed_at": null,
       "plan_path":      ".sleepwell/phases/<NN>-<slug>/PLAN.md",
       "execution_path": ".sleepwell/phases/<NN>-<slug>/EXECUTION.md",
       "verification_path": null
     }
     ```

## Output

```
phase <NN>-<slug> started
plan:      .sleepwell/phases/<NN>-<slug>/PLAN.md
execution: .sleepwell/phases/<NN>-<slug>/EXECUTION.md

next steps:
  edit PLAN.md filling in acceptance criteria
  resume the loop with /sleepwell:sleepwell-resume
```

## Edge cases

- `state.json` missing → "no sleepwell run here — start one with /sleepwell:sleepwell."
- Invalid slug (not kebab-case) → error with correction suggestion.
- Directory already exists (collision) → suffixes `-2`, `-3`, ... in the slug.
- `--plan <path>` points to non-existent file → error, does not create phase.
